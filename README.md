# Case Process Viewer Utils

[![CI Build](https://github.com/axonivy-market/case-process-viewer-utils/actions/workflows/ci.yml/badge.svg)](https://github.com/axonivy-market/case-process-viewer-utils/actions/workflows/ci.yml)

This Axon Ivy component provides a convenient way to display both your current active task and completed tasks within the same case. It helps users easily track progress and understand the case’s workflow at a glance.

Read our [documentation](case-process-viewer-utils-product/README.md).
